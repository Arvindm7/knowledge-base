# The `static` Keyword in Java

In Java, the `static` keyword is used to indicate that a member **belongs to the class** rather than to any specific instance of the class. It can be applied to variables, methods, blocks, and nested classes. Members marked as `static` are **shared across all instances** of the class, meaning they are loaded only once in memory during the class's lifecycle.

This is in contrast to non-static (instance) members, which are unique to each object created from the class.

By the end of this chapter, you'll understand:

## Static Variables in Java

### Definition

A **static variable** (also called a **class variable**) is a variable that belongs to the **class** rather than to any individual object. All instances of the class **share the same copy** of a static variable. It is declared using the `static` keyword and is initialized only **once** when the class is first loaded into memory by the JVM.

Static variables are stored in the **method area** (also called PermGen or Metaspace depending on JVM version), separate from the heap where object data lives.

### When to Use

- When a value must be **shared** across all objects (e.g., a counter tracking how many objects have been created)
- When storing **constants** or **configuration** values common to all instances
- When you want to avoid duplicating the same data in every object

### Example

```java
import java.util.*;

// Counter class
class Counter {
    static int count = 0; // static variable — shared by all instances

    // Constructor increments the shared count each time an object is created
    Counter() {
        count++;
    }

    // Static method to display count
    static void displayCount() {
        System.out.println("Count: " + count);
    }
}

// Main class
class Main {
    public static void main(String[] args) {
        Counter c1 = new Counter();
        Counter c2 = new Counter();
        Counter.displayCount(); // Output: Count: 2
    }
}
```

Here, the `count` variable is shared among all objects of the `Counter` class. Creating `c1` increments it to 1, and creating `c2` increments it to 2 — hence the output is `Count: 2`, not `Count: 0`.

**Keypoints:**
- Declared using the `static` keyword inside a class.
- Initialized only **once** when the class is loaded.
- Shared across **all instances** — changes made by one object are visible to all others.
- Can be accessed using the **class name** directly: `Counter.count`.
- Default value is assigned automatically (`0` for `int`, `null` for objects, etc.) if not initialized.

## Static Methods in Java

### Definition

A **static method** is a method that belongs to the **class** rather than to any instance of it. It can be **called without creating an object** of the class. Static methods are commonly used for **utility or helper functions** — operations that do not depend on any object-specific data.

You've already used a static method without realizing it: `public static void main(String[] args)` — the `main` method itself is static, which is why the JVM can call it without creating an object first.

### When to Use

- When the method performs an operation that is **not specific to any instance** (e.g., math calculations, string utilities)
- When implementing **factory methods** or **helper functions** in utility classes
- When you want to call a method **without object overhead**

### Example

```java
import java.util.*;

// Math Utility class
class MathUtils {
    static int add(int a, int b) {
        return a + b;
    }

    static double square(double n) {
        return n * n;
    }
}

class Main {
    public static void main(String[] args) {
        // Calling static methods without creating any object
        int result = MathUtils.add(5, 3);
        double sq = MathUtils.square(4.0);

        System.out.println("Result: " + result); // Output: Result: 8
        System.out.println("Square: " + sq);     // Output: Square: 16.0
    }
}
```

Here, the program calls `add()` and `square()` without creating an instance of `MathUtils`, because they are static methods.

**Keypoints:**
- Called using the **class name**: `MathUtils.add(5, 3)`.
- **Cannot** directly access non-static members (instance variables or methods), because those require an object.
- **Can** directly call other static methods and access static variables.
- Cannot use `this` or `super` keywords inside a static method (since they refer to an instance).

> [!NOTE]
> Static methods can access non-static members **indirectly** by first creating an instance of the class inside the method. See the [Interaction section](#interaction-between-static-and-non-static-members) below.

## Static Blocks in Java

### Definition

A **static block** (also called a **static initialization block**) is a block of code that runs **once** when the class is first loaded into memory by the JVM — before any objects are created and before any static methods are called. It is used to perform **complex initialization** of static variables that cannot be done in a single line.

A class can have **multiple static blocks**, and they are executed in the order they appear in the class.

### When to Use

- When static variable initialization requires **multiple steps** or **logic** (e.g., reading from a config file, loading a driver)
- When you need to handle **exceptions** during initialization (static blocks can use try-catch)
- When setting up shared resources that all instances will use

### Example

```java
import java.util.*;

class DatabaseConfig {
    static String host;
    static int port;
    static String dbName;

    // Static block — runs once when the class is loaded
    static {
        host = "localhost";
        port = 5432;
        dbName = "myDatabase";
        System.out.println("DatabaseConfig loaded.");
        System.out.println("Connecting to: " + host + ":" + port + "/" + dbName);
    }
}

// Main class
class Main {
    public static void main(String[] args) {
        // Just referencing the class triggers the static block
        System.out.println("Host: " + DatabaseConfig.host);
        // Output:
        // DatabaseConfig loaded.
        // Connecting to: localhost:5432/myDatabase
        // Host: localhost
    }
}
```

**Keypoints:**
- Enclosed in `static { ... }` inside the class body.
- Executed **once** when the class is first loaded — not on every object creation.
- Executed **before** any constructor or static method call.
- Multiple static blocks run in the **order they appear** in the source file.
- Can contain any valid Java statements, including `try-catch` blocks.

> [!TIP]
> If you have both a static block and static variable initializers, they are executed **top-to-bottom** in the order they appear in the class.

## Interaction Between Static and Non-Static Members

### The Rule

**Static methods cannot directly access non-static (instance) members.** This is because static methods are called on the class itself — there is no object context, so instance variables don't exist in that scope.

However, non-static members can be accessed indirectly by **creating an instance** of the class within the static method.

```java
import java.util.*;

class Example {
    int instanceVar = 10;       // non-static (instance) variable
    static int staticVar = 99;  // static (class) variable

    static void staticMethod() {
        // Direct access to staticVar — allowed
        System.out.println("Static variable: " + staticVar);

        // Direct access to instanceVar — NOT allowed (compile error)
        // System.out.println(instanceVar); // ❌ Error

        // Indirect access via object creation — allowed
        Example obj = new Example();
        System.out.println("Instance variable: " + obj.instanceVar); // ✅
    }
}

class Main {
    public static void main(String[] args) {
        Example.staticMethod();
    }
}
```

### Summary of Access Rules

| From \ To | Static Variable | Static Method | Instance Variable | Instance Method |
| :--- | :---: | :---: | :---: | :---: |
| **Static method** | ✅ | ✅ | ❌ (direct) | ❌ (direct) |
| **Instance method** | ✅ | ✅ | ✅ | ✅ |

## Advantages of Static Members in Java

- **Memory Efficiency:** Static variables are loaded into memory only once for the entire class, regardless of how many objects are created. This reduces redundant memory allocation.
- **Utility Functions:** Static methods are ideal for utility or helper functions that do not require object-specific data. Java's built-in `Math` class (`Math.sqrt()`, `Math.pow()`) is a great example.
- **Initialization Control:** Static blocks allow for controlled, one-time initialization of static variables before any object is created, ensuring shared resources are ready for use.
- **Global Access:** Static members can be accessed from anywhere using the class name, making shared state and behavior easy to reach.

### Example — Utility Class

```java
import java.util.*;

// Utility Class
class Utils {
    static void printMessage(String message) {
        System.out.println(message);
    }

    static String repeat(String str, int times) {
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < times; i++) sb.append(str);
        return sb.toString();
    }
}

class Main {
    public static void main(String[] args) {
        Utils.printMessage("Hello, Static!");     // Output: Hello, Static!
        System.out.println(Utils.repeat("ab", 3)); // Output: ababab
    }
}
```

Static members simplify scenarios where sharing resources or creating reusable methods is required — without the need to instantiate a class.
