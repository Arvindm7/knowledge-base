# Attributes

Attributes (also called **properties** or **fields**) are the data or characteristics of an object. They represent the **state** of the object at any given moment.

Attributes are typically defined within a class and can hold different types of information related to the object.

For example, we wish to create two data fields for our `BankAccount` class:

- **name:** To store the name of the account holder. The `String` data type is best suited for it.
- **balance:** To store the account balance. The `double` data type is a good fit for this.

Since `balance` is private account data, it should be hidden from the outside world. No user should be able to directly change another user's balance.

To handle such cases, the `balance` attribute must be declared with the access modifier set to `private`.

---

# Methods

Methods are functions defined inside a class that represent the **behavior** or **actions** an object can perform.

Methods define what an object can do, and they often operate on the attributes of the class. Every object of a class can call its methods to perform specific tasks.

For example, in a `BankAccount` class, different functions can be provided:

- **checkBalance:** The user can check the account balance.
- **deposit:** The user can deposit a certain amount.
- **withdraw:** The user can withdraw money from their bank account.

---

# BankAccount Implementation

Consider the following class implementing a `BankAccount` in Java:

```java
public class BankAccount {
    private String name;
    private double balance;

    public BankAccount(String name, double balance) {
        this.name = name;
        this.balance = balance;
    }

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    public double getBalance() {
        return balance;
    }

    public void deposit(double amount) {
        if (amount <= 0) {
            System.out.println("Deposit amount must be positive.");
            return;
        }
        balance += amount;
    }

    public boolean withdraw(double amount) {
        if (amount <= 0) {
            System.out.println("Withdrawal amount must be positive.");
            return false;
        }
        if (amount > balance) {
            System.out.println("Insufficient balance.");
            return false;
        }
        balance -= amount;
        return true;
    }
}
```

# Interaction Between Attributes and Methods

In a class implementing a real-world scenario, **attributes** and **methods** interact with each other constantly.

- Methods allow controlled access to the attributes.
- Attributes are often marked as `private` to restrict direct access, promoting **encapsulation**.
- Methods then provide a controlled way of interacting with those attributes.

For example, the `balance` attribute was set as `private` in the `BankAccount` class. To get the balance, a method must be implemented that can access the private attribute.

This brings us to the two major method types used in real-world OOP projects:

- **Setters:** A method to set or modify the value of a particular attribute, such as `setName()`.
- **Getters:** A method to get or retrieve the value of a particular attribute, such as `getName()`.

These methods provide controlled access to private data attributes, which otherwise cannot be accessed directly from outside the class.

# Important Points

There are some important points to keep in mind while implementing real-world entities using OOP:

- **Accessing Attributes:** Use methods (getters and setters) to access private attributes for controlled modification of data.

    ```java
    getBalance(); // retrieves the current balance
    ```

- **Encapsulation:** Keep attributes private and provide controlled access using public methods to ensure data integrity. In Java, the `private` keyword restricts outside access.

- **Default Values:** Attribute initialization rules depend on the language. In Java, member variables receive default values if not initialized explicitly (for example: numeric types -> `0`, `boolean` -> `false`, reference types -> `null`).

- **Method Parameters:** Methods can take parameters to modify attributes.

    ```java
    deposit(amount);
    ```

- **Error Handling:** Always validate inputs inside methods, such as disallowing negative deposits or withdrawals exceeding the available balance.
