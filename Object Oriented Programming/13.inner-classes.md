# Inner Classes in Java

Inner classes are classes that are **defined within another class**. They are a powerful feature in Java that allows you to logically group classes that are only used in one place, making the code more readable and encapsulated. They have **direct access to all the members** (both static and non-static) of the outer class, including private ones.

Inner classes help achieve **tighter encapsulation** — if a class is only relevant in the context of another class, it makes sense to nest it inside rather than expose it at the package level.

## What You'll Learn

By the end of this chapter, you'll understand:

- What inner classes are and why they are used
- The four types of inner classes in Java
- **Static Nested Classes** — class-level nesting without outer instance
- **Non-Static Inner Classes** — instance-tied nesting with full outer access
- **Local Inner Classes** — method-scoped class definitions
- **Anonymous Inner Classes** — one-time, nameless implementations
- When and where to use each type

---

## Types of Inner Classes

Java provides four types of inner classes to suit different use cases:

| Type | Defined Inside | Requires Outer Instance | Access to Outer Members |
| :--- | :--- | :---: | :--- |
| **Static Nested Class** | Class body (with `static`) | ❌ | Static members only |
| **Non-Static Inner Class** | Class body (without `static`) | ✅ | All members (static + instance) |
| **Local Inner Class** | A method or block | ✅ (via outer method) | All outer members + effectively final locals |
| **Anonymous Inner Class** | Expression / statement | ✅ | All outer members + effectively final locals |

## 1. Static Nested Classes

### Definition

A **static nested class** is defined with the `static` modifier inside another class. Because it is static, it does **not require an instance of the outer class** to be created — it behaves more like a regular top-level class that has simply been placed inside another class for organizational purposes.

Static nested classes **can only access the static members** of the outer class. They have no implicit reference to an instance of the outer class.

### When to Use

- When the nested class is **logically related** to the outer class but **does not need access** to instance-specific data
- When grouping **helper classes** or **builder classes** alongside the class they serve
- To improve code organization without coupling the inner class to a specific outer instance

### Example

```java
import java.util.*;

class OuterClass {
    static int staticVar = 100;
    int instanceVar = 42; // NOT accessible from static nested class

    // Static Nested Class
    static class StaticNestedClass {
        void display() {
            // Can access staticVar directly — it's static
            System.out.println("Static variable: " + staticVar);

            // Cannot access instanceVar — it requires an outer instance
            // System.out.println(instanceVar); // ❌ Compile error
        }
    }
}

// Main class
class Main {
    public static void main(String[] args) {
        // No need to create an OuterClass instance
        OuterClass.StaticNestedClass nestedObj =
            new OuterClass.StaticNestedClass();

        nestedObj.display(); // Output: Static variable: 100
    }
}
```

**Keypoints:**
- Declared using the `static` keyword inside the outer class.
- Can only access **static members** of the outer class directly.
- **No implicit reference** to an outer class instance is maintained.
- Instantiated using: `new OuterClass.StaticNestedClass()` — no outer object needed.
- Often used for **Builder patterns** (e.g., `Person.Builder`) or grouping tightly related helper classes.

> [!NOTE]
> Static nested classes are often confused with inner classes. The key distinction: **static nested classes don't hold a reference to the outer instance**, while non-static inner classes do.

## 2. Non-Static Inner Classes

### Definition

A **non-static inner class** (also simply called an **inner class**) is a class defined inside another class **without** the `static` modifier. It is **associated with a specific instance of the outer class** — meaning every inner class object implicitly holds a reference to the outer class instance that created it.

Because of this, non-static inner classes have **full access to all members** of the outer class — including private instance variables and private methods.

### When to Use

- When the inner class needs to **interact with the instance state** of the outer class
- When implementing **iterators**, **event handlers**, or **view objects** that are tightly coupled to the outer class
- When you want to **logically group** behavior that only makes sense in the context of the outer class

### Example

```java
import java.util.*;

class OuterClass {
    private int instanceVar = 42;
    private String secret = "Outer Secret";

    // Non-static Inner Class
    class InnerClass {
        void display() {
            // Can access both public and private members of outer class
            System.out.println("Instance variable: " + instanceVar);
            System.out.println("Secret: " + secret);
        }
    }
}

class Main {
    public static void main(String[] args) {
        // Must first create an outer class instance
        OuterClass outerObj = new OuterClass();

        // Then create the inner class instance using the outer instance
        OuterClass.InnerClass innerObj = outerObj.new InnerClass();

        innerObj.display();
        // Output:
        // Instance variable: 42
        // Secret: Outer Secret
    }
}
```

**Keypoints:**
- Declared **without** the `static` keyword inside the outer class.
- **Requires** an instance of the outer class to be instantiated: `outerObj.new InnerClass()`.
- Has access to **all members** of the outer class (including `private`).
- Implicitly holds a reference to the outer class instance (`OuterClass.this`).
- Can reference the outer class explicitly: `OuterClass.this.instanceVar`.

> [!WARNING]
> Because non-static inner classes hold a reference to the outer instance, they can **prevent garbage collection** of the outer object. Be mindful of memory leaks in long-lived inner class instances.

## 3. Local Inner Classes

### Definition

A **local inner class** is a class defined **inside a method, constructor, or a block of code**. It exists only within the **scope of that method or block** and cannot be accessed from outside it. Local inner classes are similar to non-static inner classes — they can access all members of the outer class — but additionally, they can access **local variables** of the enclosing method, provided those variables are **effectively final** (i.e., their value is not changed after initialization).

### What is "Effectively Final"?

A variable is effectively final if it is **never reassigned** after its initial assignment — even if it's not explicitly declared with the `final` keyword. Java requires this to ensure that the inner class always sees a consistent value for the variable.

### When to Use

- When you need a **helper class only within a single method**
- When you want to **encapsulate complex logic** in one place without polluting the outer class
- When implementing **strategy patterns** or **temporary callbacks** scoped to one operation

### Example

```java
import java.util.*;

class OuterClass {
    private String outerData = "Outer Data";

    void outerMethod() {
        int localVar = 10; // effectively final — never reassigned

        // Local Inner Class — only visible inside outerMethod()
        class LocalInnerClass {
            void display() {
                // Can access outer class members
                System.out.println("Outer data: " + outerData);
                // Can access effectively final local variables
                System.out.println("Local variable: " + localVar);
            }
        }

        LocalInnerClass localInner = new LocalInnerClass();
        localInner.display();
    }
}

// Main Class
class Main {
    public static void main(String[] args) {
        OuterClass outerObj = new OuterClass();
        outerObj.outerMethod();
        // Output:
        // Outer data: Outer Data
        // Local variable: 10
    }
}
```

**Keypoints:**
- Defined **within a method or block** — invisible outside that scope.
- Can access **all members** of the outer class.
- Can only access **effectively final** local variables of the enclosing method.
- Cannot have `static` members.
- Cannot be accessed from outside the method where they are defined.

> [!TIP]
> Local inner classes are rarely used in modern Java. Lambda expressions (Java 8+) are often a cleaner alternative for the same use cases.

## 4. Anonymous Inner Classes

### Definition

An **anonymous inner class** is a type of local inner class that has **no name**. It is declared and instantiated **at the same time**, in a single expression. Anonymous inner classes are typically used to provide a **one-time, on-the-spot implementation** of an abstract class or interface, without the overhead of defining a full named class.

They are especially common in older Java code for implementing event listeners, callbacks, and strategies inline. Since Java 8, lambda expressions have replaced many of their use cases for functional interfaces.

### When to Use

- When you need to **implement an interface or extend a class** only once
- When the implementation is **short and doesn't warrant a full named class**
- In **GUI applications** (Swing, JavaFX) for event listeners
- For **quick overrides** in testing or utility code

### Example 1 — Extending an Abstract Class

```java
import java.util.*;

abstract class Greeting {
    abstract void sayHello();
}

class Main {
    public static void main(String[] args) {
        // Anonymous inner class — extends Greeting and overrides sayHello()
        Greeting greeting = new Greeting() {
            @Override
            void sayHello() {
                System.out.println("Hello, World!");
            }
        };

        greeting.sayHello(); // Output: Hello, World!
    }
}
```

### Example 2 — Implementing an Interface

```java
import java.util.*;

interface Printable {
    void print();
}

class Main {
    public static void main(String[] args) {
        // Anonymous inner class implementing Printable interface
        Printable p = new Printable() {
            @Override
            public void print() {
                System.out.println("Printing from anonymous class!");
            }
        };

        p.print(); // Output: Printing from anonymous class!
    }
}
```

**Keypoints:**
- Have **no name** — declared and instantiated in one expression.
- **Instantiated at the point of declaration** using `new ClassName/InterfaceName() { ... }`.
- Typically used when a class is needed **only once**.
- Can extend a class **or** implement an interface — but not both at the same time.
- Cannot have **explicit constructors** (since they have no name).
- Commonly used in **GUI event listeners** and **callback implementations**.

> [!NOTE]
> Since Java 8, **lambda expressions** are preferred over anonymous inner classes when implementing **functional interfaces** (interfaces with a single abstract method). For example: `Runnable r = () -> System.out.println("Running");` replaces a 5-line anonymous class.

## Comparison of All Inner Class Types

| Feature | Static Nested | Non-Static Inner | Local Inner | Anonymous Inner |
| :--- | :---: | :---: | :---: | :---: |
| Has a name | ✅ | ✅ | ✅ | ❌ |
| Requires outer instance | ❌ | ✅ | ✅ | ✅ |
| Access to outer static members | ✅ | ✅ | ✅ | ✅ |
| Access to outer instance members | ❌ | ✅ | ✅ | ✅ |
| Access to local variables | ❌ | ❌ | ✅ (effectively final) | ✅ (effectively final) |
| Can have `static` members | ✅ | ❌ | ❌ | ❌ |
| Defined at class level | ✅ | ✅ | ❌ | ❌ |

## Summary

| Concept | Description |
| :--- | :--- |
| **Inner Class** | A class defined inside another class for better encapsulation |
| **Static Nested Class** | Does not need an outer instance; accesses only static members |
| **Non-Static Inner Class** | Tied to an outer instance; accesses all outer members |
| **Local Inner Class** | Defined inside a method; only accessible within that method |
| **Anonymous Inner Class** | Nameless class for one-time implementations of interfaces/abstract classes |
| **Effectively Final** | A local variable whose value is never changed after first assignment |
