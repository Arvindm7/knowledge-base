# What is Java?

Java is a **high-level, object-oriented, class-based programming language** developed by **Sun Microsystems** in 1995 (now owned by Oracle).

Java was designed with one major goal:

> **Write Once, Run Anywhere (WORA)**

This means Java code written on one operating system can run on any other operating system without modification.

For example, a Java application written on Windows can run on:

- Windows
- Linux
- macOS

without changing the source code.

---

# Why Was Java Created?

Before Java, software was usually written specifically for one operating system.

Problems included:

- Platform dependency
- Difficult maintenance
- Poor portability
- Security issues

Java solved these problems by introducing the **Java Virtual Machine (JVM)**.

# Features of Java

## 1. Simple

Java removes many complex features of C++ like:

- Multiple inheritance through classes
- Pointer arithmetic
- Manual memory management

---

## 2. Object-Oriented

Everything revolves around objects and classes.

Major OOP principles:

- Encapsulation
- Inheritance
- Polymorphism
- Abstraction

---

## 3. Platform Independent

Java source code is compiled into **Bytecode**.

Bytecode runs inside the JVM.

This makes Java platform-independent.

---

## 4. Secure

Java provides security through:

- Bytecode verification
- No direct memory access
- Class Loader
- Security Manager (legacy concept)

---

## 5. Robust

Java is reliable because of:

- Exception handling
- Garbage Collection
- Strong memory management

---

## 6. Multithreaded

Java allows multiple tasks to run simultaneously.

Example:

- Playing music
- Downloading files
- Browsing the internet

all at the same time.

---

## 7. High Performance

Although Java is interpreted by the JVM, modern JVMs use **JIT (Just-In-Time) Compilation** to improve performance.

---

## 8. Distributed

Java supports distributed computing using:

- RMI
- Web Services
- Networking APIs

---

## 9. Dynamic

Java loads classes during runtime, making applications flexible and extensible.

# JDK vs JRE vs JVM

Understanding these three components is essential.

## JVM (Java Virtual Machine)

The JVM is responsible for executing Java bytecode.

Responsibilities:

- Loads classes
- Executes bytecode
- Manages memory
- Performs garbage collection

Think of JVM as the **engine** that runs Java programs.

---

## JRE (Java Runtime Environment)

JRE contains:

- JVM
- Libraries
- Supporting files

It allows users to **run** Java applications.

It **cannot** compile Java code.

---

## JDK (Java Development Kit)

JDK contains:

- JRE
- JVM
- Java Compiler (javac)
- Debugger
- Documentation tools

Developers install the JDK to build Java applications.

---

# Relationship

```
JDK
 ├── JRE
 │     ├── JVM
 │     └── Libraries
 └── Development Tools
```

# How Java Works

Suppose we write:

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello Java");
    }
}
```

The execution happens in several steps.

---

## Step 1

Write source code.

```
Main.java
```

↓

## Step 2

Compile the source code.

```
javac Main.java
```

↓

Compiler generates:

```
Main.class
```

This is **Bytecode**.

↓

## Step 3

The JVM loads the bytecode.

↓

## Step 4

The JVM converts bytecode into machine code using the **JIT Compiler**.

↓

## Step 5

The operating system executes the machine code.

---

# Java Execution Flow

```
Source Code (.java)
        │
        ▼
Java Compiler (javac)
        │
        ▼
Bytecode (.class)
        │
        ▼
JVM
        │
        ▼
Machine Code
        │
        ▼
Output
```
