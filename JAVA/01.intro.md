## What is Java?

Java is a **high-level, object-oriented, class-based programming language** created by **Sun Microsystems** in 1995. Today, it is maintained by Oracle.

Java was designed with a central idea:

> **Write Once, Run Anywhere (WORA)**

This means Java code compiled on one operating system can run on any other operating system without modification. For example, a Java application written on Windows can also run on Linux or macOS.

---

## Why Was Java Created?

Before Java, most programs were tied to a single operating system. This caused problems like:

- platform dependency
- difficult maintenance
- poor portability
- security issues

Java solved these problems by introducing the **Java Virtual Machine (JVM)** and platform-independent bytecode.

## Java Features

### 1. Simple
Java avoids complex C++ features such as:
- multiple inheritance through classes
- pointer arithmetic
- manual memory management

### 2. Object-Oriented
Java uses objects and classes to model real-world problems.
Key principles:
- encapsulation
- inheritance
- polymorphism
- abstraction

### 3. Platform Independent
Java source code is compiled into **bytecode**, which runs on the JVM. This makes Java programs platform independent.

### 4. Secure
Java provides security through:
- bytecode verification
- restricted memory access
- class loaders

### 5. Robust
Java is designed to be reliable:
- exception handling
- garbage collection
- strong memory management

### 6. Multithreaded
Java supports concurrent execution:
- run multiple tasks at once
- build responsive applications

### 7. High Performance
Modern JVMs use **JIT (Just-In-Time) compilation** to improve performance.

### 8. Distributed
Java supports distributed computing:
- RMI
- web services
- networking APIs

### 9. Dynamic
Java loads classes at runtime, making applications flexible and extensible.

## JDK vs JRE vs JVM

### JVM (Java Virtual Machine)
The JVM executes Java bytecode and handles:
- class loading
- memory management
- garbage collection

It is the engine that runs Java programs.

### JRE (Java Runtime Environment)
The JRE includes:
- JVM
- libraries
- runtime support

It allows you to run Java applications but not compile them.

### JDK (Java Development Kit)
The JDK includes:
- JRE
- JVM
- Java compiler (`javac`)
- development tools
- debugging tools

Install the JDK to build Java applications.

### Relationship

```
JDK
├── JRE
│     ├── JVM
│     └── Libraries
└── Developer Tools
```

## How Java Works

**Execution steps:**

1. You write `.java` source code
2. The `javac` compiler converts it to `.class` **bytecode**
3. The JVM reads and executes the bytecode on any platform

## Your First Java Program

Let's look at the most basic Java program: **Hello World**.

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello World");
    }
}
```

### Understanding the Parts

| Part | Meaning |
| :--- | :--- |
| `class Main` | Everything in Java lives inside a class. The file should be named `Main.java`. |
| `public` | Access modifier — accessible from anywhere. |
| `static` | Can be called without creating an object of the class. |
| `void` | The method does not return any value. |
| `main` | The entry point — execution always starts here. |
| `String[] args` | Command-line arguments passed when running the program. |
| `System.out.println` | Prints output to the screen and moves to a new line. |

## Strings

Strings are **objects** in Java, not primitives. They store text and are **immutable** — once created, a String object cannot be changed. Modifying it creates a new object.

```java
String s1 = "Hello";
char[] arr = {'W', 'o', 'r', 'l', 'd'};
String s2 = new String(arr); // char array to String

System.out.println(s1 + " " + s2);    // Concatenation: Hello World
System.out.println(s1.charAt(1));      // Char at index 1: 'e'
System.out.println(s1.length());       // Length: 5
System.out.println(s1.substring(0, 2)); // Substring: "He"
System.out.println(s1.equals("Hello")); // Content equality: true
```

> [!NOTE]
> Use `.equals()` to compare String content, **not** `==`. The `==` operator checks if both variables point to the same object in memory, not whether their values are equal.

## Input / Output

For reading user input, Java provides the `Scanner` class.

```java
import java.util.Scanner;

public class InputExample {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int age = sc.nextInt();
        String name = sc.next();
        System.out.println(name + " is " + age);
        sc.close();
    }
}
```

> [!TIP]
> **What about `BufferedReader`?** `BufferedReader` is faster but requires manually parsing strings to numbers. `Scanner` is simpler and preferred for beginners.

## Arrays

Arrays store multiple values of the **same type** in a single variable.

```java
int[] scores = {90, 80, 70};

System.out.println(scores.length); // 3
System.out.println(scores[0]);     // 90

// For-Each Loop
for (int score : scores) {
    System.out.println(score);
}

// 2D Array
int[][] matrix = { {1, 2}, {3, 4} };
System.out.println(matrix[0][1]); // 2
```

## Conditional Statements

### If / Else If / Else

```java
int marks = 85;

if (marks > 90) {
    System.out.println("A");
} else if (marks > 80) {
    System.out.println("B");
} else {
    System.out.println("C");
}
```

The program checks `marks > 90`. Since 85 is not greater than 90, it moves to `marks > 80`. This is true, so it prints `"B"`. The rest of the chain is skipped.

### Switch

```java
int day = 2;

switch (day) {
    case 1:
        System.out.println("Monday");
        break;
    case 2:
        System.out.println("Tuesday");
        break;
    default:
        System.out.println("Invalid");
}
```

- **`break`:** Stops execution from falling through to the next case.
- **`default`:** Runs if no case matches (like `else`).

## Loops

### For Loop

```java
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}
```

### While Loop

```java
int i = 0;
while (i < 5) {
    System.out.println(i);
    i++;
}
```

### Do-While Loop

```java
int i = 0;
do {
    System.out.println(i); // Runs at least once
    i++;
} while (i < 5);
```

> [!NOTE]
> The `do-while` loop **always executes its body at least once**, even if the condition is false from the start — unlike `while` and `for`.

## Exception Handling

Exception handling prevents the program from crashing when an error occurs.

```java
try {
    int[] myNumbers = {1, 2, 3};
    System.out.println(myNumbers[10]); // Throws ArrayIndexOutOfBoundsException
} catch (Exception e) {
    System.out.println("Something went wrong: " + e.getMessage());
} finally {
    System.out.println("This always runs, whether or not an exception occurred.");
}
```

| Block | Purpose |
| :--- | :--- |
| `try` | Contains the code that might throw an exception |
| `catch` | Handles the exception if one is thrown |
| `finally` | Always runs regardless of whether an exception occurred |
