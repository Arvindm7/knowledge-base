## What is Java?

Java is a **high-level, object-oriented, class-based programming language** created by **Sun Microsystems** in 1995. Today, it is maintained by Oracle.

Java was designed with a central idea:

> **Write Once, Run Anywhere (WORA)**

This means Java code compiled on one operating system can run on any other operating system without modification. For example, a Java application written on Windows can also run on Linux or macOS.

---

## Why Was Java Created?

Before Java, most programs were tied to a single operating system. This caused problems like:

- platform dependency
- difficult maintenance
- poor portability
- security issues

Java solved these problems by introducing the **Java Virtual Machine (JVM)** and platform-independent bytecode.

## Java Features

### 1. Simple
Java avoids complex C++ features such as:
- multiple inheritance through classes
- pointer arithmetic
- manual memory management

### 2. Object-Oriented
Java uses objects and classes to model real-world problems.
Key principles:
- encapsulation
- inheritance
- polymorphism
- abstraction

### 3. Platform Independent
Java source code is compiled into **bytecode**, which runs on the JVM. This makes Java programs platform independent.

### 4. Secure
Java provides security through:
- bytecode verification
- restricted memory access
- class loaders

### 5. Robust
Java is designed to be reliable:
- exception handling
- garbage collection
- strong memory management

### 6. Multithreaded
Java supports concurrent execution:
- run multiple tasks at once
- build responsive applications

### 7. High Performance
Modern JVMs use **JIT (Just-In-Time) compilation** to improve performance.

### 8. Distributed
Java supports distributed computing:
- RMI
- web services
- networking APIs

### 9. Dynamic
Java loads classes at runtime, making applications flexible and extensible.

## JDK vs JRE vs JVM

### JVM (Java Virtual Machine)
The JVM executes Java bytecode and handles:
- class loading
- memory management
- garbage collection

It is the engine that runs Java programs.

### JRE (Java Runtime Environment)
The JRE includes:
- JVM
- libraries
- runtime support

It allows you to run Java applications but not compile them.

### JDK (Java Development Kit)
The JDK includes:
- JRE
- JVM
- Java compiler (`javac`)
- development tools
- debugging tools

Install the JDK to build Java applications.

### Relationship

    JDK
    ├── JRE
    │     ├── JVM
    │     └── Libraries
    └── Developer Tools
