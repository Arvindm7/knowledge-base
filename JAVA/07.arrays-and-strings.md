## What is an Array?

An **array** is a container that holds a **fixed number** of values of the **same type**. Once created, its size cannot change.

```java
int[] scores = new int[5];  // An array of 5 integers, all initialised to 0
```

### Why Use Arrays?

Without arrays, storing 100 student marks would require 100 separate variables. Arrays let you store them in a single variable and access each by its **index**.

## Declaring and Creating Arrays

There are multiple ways to create an array:

### Method 1: Declare, Then Create

```java
int[] numbers;          // Declaration — no array exists yet
numbers = new int[5];   // Creation — allocates memory for 5 integers
```

### Method 2: Declare and Create in One Line

```java
int[] numbers = new int[5];
```

### Method 3: Declare, Create, and Initialise

```java
int[] numbers = {10, 20, 30, 40, 50};  // Size is automatically 5
```

### Method 4: Using `new` with Values

```java
int[] numbers = new int[]{10, 20, 30, 40, 50};
```

> [!NOTE]
> When you create an array with `new int[5]` without providing values, Java fills it with **default values**: `0` for numbers, `false` for booleans, `null` for objects.

## Accessing and Modifying Elements

Array elements are accessed by their **index**, starting from `0`:

```java
int[] marks = {85, 92, 78, 95, 88};

System.out.println(marks[0]);   // 85 — first element
System.out.println(marks[4]);   // 88 — last element
System.out.println(marks.length); // 5 — number of elements

marks[2] = 80;  // Change the third element from 78 to 80
System.out.println(marks[2]);   // 80
```

### Index Rules

| Property | Value |
| :--- | :--- |
| **First index** | `0` |
| **Last index** | `array.length - 1` |
| **Out of bounds** | Throws `ArrayIndexOutOfBoundsException` |

```java
int[] arr = {10, 20, 30};
// System.out.println(arr[3]);  // RUNTIME ERROR — index 3 does not exist
// System.out.println(arr[-1]); // RUNTIME ERROR — negative index
```

## Iterating Over Arrays

### Using a `for` Loop (With Index)

```java
int[] numbers = {10, 20, 30, 40, 50};

for (int i = 0; i < numbers.length; i++) {
    System.out.println("Index " + i + ": " + numbers[i]);
}
```

Use this when you need the **index** for operations like swapping or comparing adjacent elements.

### Using a `for-each` Loop (Without Index)

```java
int[] numbers = {10, 20, 30, 40, 50};

for (int num : numbers) {
    System.out.println(num);
}
```

Cleaner and simpler. Use this when you only need to **read** each element.

### Using `while` Loop

```java
int[] numbers = {10, 20, 30, 40, 50};
int i = 0;

while (i < numbers.length) {
    System.out.println(numbers[i]);
    i++;
}
```

## Multi-Dimensional Arrays (2D Arrays)

A **2D array** is an array of arrays — like a table with rows and columns:

```java
int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};
```

### Accessing Elements

```java
System.out.println(matrix[0][0]);  // 1 — row 0, column 0
System.out.println(matrix[1][2]);  // 6 — row 1, column 2
System.out.println(matrix[2][1]);  // 8 — row 2, column 1
```

### Iterating Over a 2D Array

```java
for (int row = 0; row < matrix.length; row++) {
    for (int col = 0; col < matrix[row].length; col++) {
        System.out.printf("%4d", matrix[row][col]);
    }
    System.out.println();
}
```

Output:

```text
   1   2   3
   4   5   6
   7   8   9
```

### Creating a 2D Array with `new`

```java
int[][] grid = new int[3][4];  // 3 rows, 4 columns — all values are 0
```

## Jagged Arrays — Rows of Different Lengths

In Java, 2D arrays can have rows of **different sizes**:

```java
int[][] jagged = new int[3][];  // 3 rows, column count not fixed
jagged[0] = new int[]{1, 2};         // Row 0 has 2 elements
jagged[1] = new int[]{3, 4, 5};      // Row 1 has 3 elements
jagged[2] = new int[]{6};            // Row 2 has 1 element

for (int[] row : jagged) {
    for (int val : row) {
        System.out.print(val + " ");
    }
    System.out.println();
}
```

Output:

```text
1 2 
3 4 5 
6 
```

## The `Arrays` Utility Class

Java provides the `java.util.Arrays` class with helpful static methods:

```java
import java.util.Arrays;
```

### Sorting

```java
int[] arr = {5, 2, 8, 1, 9, 3};
Arrays.sort(arr);
System.out.println(Arrays.toString(arr));  // [1, 2, 3, 5, 8, 9]
```

### Sorting a Range

```java
int[] arr = {5, 2, 8, 1, 9, 3};
Arrays.sort(arr, 1, 4);  // Sort indices 1 to 3 (exclusive end)
System.out.println(Arrays.toString(arr));  // [5, 1, 2, 8, 9, 3]
```

### Searching (Binary Search)

```java
int[] arr = {1, 2, 3, 5, 8, 9};  // Must be sorted first!
int index = Arrays.binarySearch(arr, 5);
System.out.println("Found at index: " + index);  // 3
```

> [!IMPORTANT]
> `binarySearch` only works on **sorted** arrays. If the array is not sorted, the result is undefined.

### Filling

```java
int[] arr = new int[5];
Arrays.fill(arr, 7);
System.out.println(Arrays.toString(arr));  // [7, 7, 7, 7, 7]
```

### Copying

```java
int[] original = {1, 2, 3, 4, 5};
int[] copy = Arrays.copyOf(original, 3);      // [1, 2, 3] — first 3 elements
int[] range = Arrays.copyOfRange(original, 1, 4); // [2, 3, 4] — indices 1 to 3
```

### Comparing

```java
int[] a = {1, 2, 3};
int[] b = {1, 2, 3};
int[] c = {1, 2, 4};

System.out.println(Arrays.equals(a, b));  // true
System.out.println(Arrays.equals(a, c));  // false
```

### Printing

```java
int[] arr = {1, 2, 3};
System.out.println(arr);                   // [I@1234abcd — NOT useful!
System.out.println(Arrays.toString(arr));  // [1, 2, 3] — human-readable
```

> [!TIP]
> Always use `Arrays.toString()` to print arrays. Printing an array variable directly shows the memory address, not the contents.

## Common Array Algorithms

### Reversing an Array

```java
public static void reverse(int[] arr) {
    int left = 0;
    int right = arr.length - 1;

    while (left < right) {
        // Swap elements
        int temp = arr[left];
        arr[left] = arr[right];
        arr[right] = temp;

        left++;
        right--;
    }
}

// Usage
int[] data = {1, 2, 3, 4, 5};
reverse(data);
System.out.println(Arrays.toString(data));  // [5, 4, 3, 2, 1]
```

### Finding the Maximum

```java
public static int findMax(int[] arr) {
    int max = arr[0];
    for (int i = 1; i < arr.length; i++) {
        if (arr[i] > max) {
            max = arr[i];
        }
    }
    return max;
}
```

### Checking for Duplicates

```java
public static boolean hasDuplicates(int[] arr) {
    for (int i = 0; i < arr.length; i++) {
        for (int j = i + 1; j < arr.length; j++) {
            if (arr[i] == arr[j]) {
                return true;
            }
        }
    }
    return false;
}
```

## Strings in Depth

### What is a String?

A `String` in Java is an **object** that represents a sequence of characters. It is **not** a primitive type — it is a class defined in `java.lang.String`.

```java
String greeting = "Hello, World!";
```

### Strings Are Immutable

Once a `String` object is created, its content **cannot be changed**. Any operation that seems to modify a String actually creates a **new** String object:

```java
String s = "Hello";
s = s + " World";  // Creates a new String "Hello World"
                    // The original "Hello" is now eligible for garbage collection
```

### Why Immutability?

| Reason | Explanation |
| :--- | :--- |
| **Security** | Strings are used for passwords, file paths, network connections — immutability prevents tampering |
| **Thread safety** | Immutable objects can be shared between threads without synchronisation |
| **String pool** | JVM can reuse identical Strings because they never change |
| **Hashing** | `hashCode()` can be cached since the content never changes |

### The String Pool

Java maintains a special memory area called the **String Pool** to save memory:

```java
String s1 = "Hello";  // Created in the String Pool
String s2 = "Hello";  // Reuses the same object from the pool

System.out.println(s1 == s2);      // true — same object in memory
System.out.println(s1.equals(s2)); // true — same content

String s3 = new String("Hello");   // Created on the heap, NOT in the pool
System.out.println(s1 == s3);      // false — different objects
System.out.println(s1.equals(s3)); // true — same content
```

> [!IMPORTANT]
> **Always use `.equals()` to compare String content**, not `==`. The `==` operator checks if two variables point to the **same object in memory**, which is not what you usually want.

## Essential String Methods

Here are the methods you will use most often:

### Length and Character Access

```java
String s = "Hello, World!";

s.length()       // 13 — number of characters
s.charAt(0)      // 'H' — character at index 0
s.charAt(7)      // 'W' — character at index 7
```

### Searching

```java
String s = "Hello, World!";

s.indexOf('o')          // 4 — first occurrence of 'o'
s.lastIndexOf('o')      // 8 — last occurrence of 'o'
s.indexOf("World")      // 7 — first occurrence of substring
s.contains("World")     // true — checks if substring exists
s.startsWith("Hello")   // true
s.endsWith("!")          // true
```

### Extracting Substrings

```java
String s = "Hello, World!";

s.substring(7)       // "World!" — from index 7 to end
s.substring(0, 5)    // "Hello" — from index 0 to 4 (end exclusive)
```

### Case Conversion

```java
String s = "Hello, World!";

s.toUpperCase()   // "HELLO, WORLD!"
s.toLowerCase()   // "hello, world!"
```

### Trimming Whitespace

```java
String s = "   Hello   ";

s.trim()      // "Hello" — removes leading and trailing whitespace
s.strip()     // "Hello" — Java 11+, handles Unicode whitespace too
```

### Replacing

```java
String s = "Hello, World!";

s.replace('o', '0')           // "Hell0, W0rld!"
s.replace("World", "Java")    // "Hello, Java!"
s.replaceAll("[aeiou]", "*")  // "H*ll*, W*rld!" — regex replacement
```

### Splitting

```java
String csv = "Alice,Bob,Charlie,Diana";
String[] names = csv.split(",");

for (String name : names) {
    System.out.println(name);
}
// Alice
// Bob
// Charlie
// Diana
```

### Joining (Java 8+)

```java
String result = String.join(" - ", "Alice", "Bob", "Charlie");
System.out.println(result);  // Alice - Bob - Charlie

String[] arr = {"one", "two", "three"};
String joined = String.join(", ", arr);
System.out.println(joined);  // one, two, three
```

### Comparing

```java
String a = "Hello";
String b = "hello";

a.equals(b)             // false — case-sensitive
a.equalsIgnoreCase(b)   // true — ignores case
a.compareTo(b)          // negative value — "H" comes before "h" in Unicode
```

### Checking for Empty or Blank

```java
String empty = "";
String blank = "   ";

empty.isEmpty()   // true — length is 0
blank.isEmpty()   // false — length is 3
blank.isBlank()   // true — Java 11+, only whitespace
```

### Quick Reference Table

| Method | Returns | Description |
| :--- | :--- | :--- |
| `length()` | `int` | Number of characters |
| `charAt(i)` | `char` | Character at index `i` |
| `indexOf(ch)` | `int` | First index of character/substring, or `-1` |
| `substring(start, end)` | `String` | Substring from `start` to `end - 1` |
| `toUpperCase()` | `String` | Converts to uppercase |
| `toLowerCase()` | `String` | Converts to lowercase |
| `trim()` | `String` | Removes leading/trailing whitespace |
| `replace(old, new)` | `String` | Replaces all occurrences |
| `split(regex)` | `String[]` | Splits into array by delimiter |
| `contains(seq)` | `boolean` | Checks if substring exists |
| `equals(obj)` | `boolean` | Content equality (case-sensitive) |
| `equalsIgnoreCase(str)` | `boolean` | Content equality (case-insensitive) |
| `isEmpty()` | `boolean` | True if length is 0 |

## `StringBuilder` — Mutable Strings

Since Strings are immutable, repeatedly modifying them creates many temporary objects and wastes memory. `StringBuilder` is a **mutable** alternative:

### The Problem with String Concatenation in Loops

```java
// BAD — creates a new String object on every iteration
String result = "";
for (int i = 0; i < 10000; i++) {
    result += i + " ";  // Creates 10,000 temporary String objects!
}
```

### The Solution — Use `StringBuilder`

```java
// GOOD — modifies the same object in place
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 10000; i++) {
    sb.append(i).append(" ");
}
String result = sb.toString();
```

### `StringBuilder` Methods

```java
StringBuilder sb = new StringBuilder("Hello");

sb.append(" World");     // "Hello World"
sb.insert(5, ",");       // "Hello, World"
sb.delete(5, 6);         // "Hello World" — removes index 5
sb.replace(6, 11, "Java"); // "Hello Java"
sb.reverse();            // "avaJ olleH"

int len = sb.length();       // Length
char ch = sb.charAt(0);      // Character at index
String str = sb.toString();   // Convert to String
```

### `StringBuilder` vs `StringBuffer`

| Feature | `StringBuilder` | `StringBuffer` |
| :--- | :--- | :--- |
| **Mutable** | Yes | Yes |
| **Thread-safe** | No | Yes (synchronised) |
| **Performance** | Faster | Slower (synchronisation overhead) |
| **Use when** | Single-threaded code | Multi-threaded code |

> [!TIP]
> Use `StringBuilder` for almost all cases. Use `StringBuffer` only when multiple threads are modifying the same string simultaneously.

## Converting Between Arrays and Strings

### String to Character Array

```java
String s = "Hello";
char[] chars = s.toCharArray();

for (char c : chars) {
    System.out.print(c + " ");  // H e l l o
}
```

### Character Array to String

```java
char[] chars = {'J', 'a', 'v', 'a'};
String s = new String(chars);
System.out.println(s);  // Java

// Or using String.valueOf
String s2 = String.valueOf(chars);
```

### Array of Strings to Single String

```java
String[] words = {"Java", "is", "awesome"};
String sentence = String.join(" ", words);
System.out.println(sentence);  // Java is awesome
```

### String to Array of Words

```java
String sentence = "Java is awesome";
String[] words = sentence.split(" ");
// words = ["Java", "is", "awesome"]
```

## Practical Examples

### Example 1: Counting Vowels in a String

```java
public class VowelCounter {
    public static int countVowels(String str) {
        int count = 0;
        str = str.toLowerCase();

        for (int i = 0; i < str.length(); i++) {
            char ch = str.charAt(i);
            if (ch == 'a' || ch == 'e' || ch == 'i' || ch == 'o' || ch == 'u') {
                count++;
            }
        }
        return count;
    }

    public static void main(String[] args) {
        String text = "Hello World";
        System.out.println("Vowels: " + countVowels(text));  // 3
    }
}
```

### Example 2: Checking if a String is a Palindrome

```java
public class PalindromeCheck {
    public static boolean isPalindrome(String str) {
        str = str.toLowerCase().replaceAll("[^a-z0-9]", "");

        int left = 0;
        int right = str.length() - 1;

        while (left < right) {
            if (str.charAt(left) != str.charAt(right)) {
                return false;
            }
            left++;
            right--;
        }
        return true;
    }

    public static void main(String[] args) {
        System.out.println(isPalindrome("racecar"));       // true
        System.out.println(isPalindrome("A man a plan a canal Panama")); // true
        System.out.println(isPalindrome("hello"));         // false
    }
}
```

### Example 3: Rotating an Array

```java
import java.util.Arrays;

public class ArrayRotation {
    public static void rotateRight(int[] arr, int k) {
        int n = arr.length;
        k = k % n;  // Handle k > array length

        reverse(arr, 0, n - 1);     // Reverse entire array
        reverse(arr, 0, k - 1);     // Reverse first k elements
        reverse(arr, k, n - 1);     // Reverse remaining elements
    }

    private static void reverse(int[] arr, int start, int end) {
        while (start < end) {
            int temp = arr[start];
            arr[start] = arr[end];
            arr[end] = temp;
            start++;
            end--;
        }
    }

    public static void main(String[] args) {
        int[] arr = {1, 2, 3, 4, 5};
        rotateRight(arr, 2);
        System.out.println(Arrays.toString(arr));  // [4, 5, 1, 2, 3]
    }
}
```

## Summary

| Concept | Key Points |
| :--- | :--- |
| **Array** | Fixed-size, same-type container; indices start at `0` |
| **Declaration** | `int[] arr = new int[5]` or `int[] arr = {1, 2, 3}` |
| **Default values** | `0` for numbers, `false` for booleans, `null` for objects |
| **2D arrays** | Array of arrays; `matrix[row][col]` for access |
| **Jagged arrays** | 2D arrays where each row can have a different length |
| **`Arrays` class** | Utility methods: `sort`, `binarySearch`, `fill`, `copyOf`, `toString`, `equals` |
| **String** | Immutable object; use `.equals()` for comparison, never `==` |
| **String pool** | JVM reuses identical String literals to save memory |
| **String methods** | `length`, `charAt`, `indexOf`, `substring`, `split`, `replace`, `trim` |
| **`StringBuilder`** | Mutable string; use for concatenation in loops; faster than `String +` |
| **`StringBuffer`** | Thread-safe mutable string; slower than `StringBuilder` |
| **Conversions** | `toCharArray()`, `new String(char[])`, `String.join()`, `split()` |
