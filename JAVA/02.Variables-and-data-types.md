## What is a Variable?

A **variable** is a named container that stores a value in memory. In Java, every variable must have a declared **data type**, which tells the compiler what kind of data it can hold.

```java
int age = 25;
```

Here:
- `int` is the data type
- `age` is the variable name
- `25` is the value assigned

## Declaring vs Initializing

```java
int score;       // declaration only
score = 100;      // initialization

int total = 50;   // declaration + initialization in one line
```

## Java Data Types

Java has two categories of data types: **primitive** and **reference (non-primitive)**.

### 1. Primitive Data Types

| Type      | Size    | Default Value | Example              |
|-----------|---------|----------------|----------------------|
| `byte`    | 1 byte  | 0              | `byte b = 10;`       |
| `short`   | 2 bytes | 0              | `short s = 1000;`    |
| `int`     | 4 bytes | 0              | `int i = 100000;`    |
| `long`    | 8 bytes | 0L             | `long l = 100000L;`  |
| `float`   | 4 bytes | 0.0f           | `float f = 3.14f;`   |
| `double`  | 8 bytes | 0.0d           | `double d = 3.14159;`|
| `char`    | 2 bytes | '\u0000'       | `char c = 'A';`      |
| `boolean` | 1 bit   | false          | `boolean flag = true;`|

### 2. Reference Data Types

These include `String`, arrays, classes, and interfaces. Unlike primitives, they store a reference (memory address) to the actual object.

```java
String name = "Alice";
int[] numbers = {1, 2, 3};
```

## Naming Rules for Variables

- Must start with a letter, `_`, or `$`
- Cannot start with a digit
- Case-sensitive (`age` and `Age` are different)
- Cannot use Java reserved keywords (e.g., `int`, `class`, `public`)
- Convention: use **camelCase** (e.g., `studentName`, `totalScore`)

## Type Casting

### Implicit (Widening) Casting
Automatically converts a smaller type to a larger type.

```java
int myInt = 9;
double myDouble = myInt; // int -> double, automatic
```

### Explicit (Narrowing) Casting
Manually convert a larger type to a smaller type using parentheses.

```java
double myDouble = 9.78;
int myInt = (int) myDouble; // double -> int, manual
```

## Constants

Use the `final` keyword to declare a variable whose value cannot change.

```java
final double PI = 3.14159;
```

## Example Program

```java
public class VariablesDemo {
    public static void main(String[] args) {
        int age = 21;
        double height = 5.9;
        char grade = 'A';
        boolean isStudent = true;
        String name = "John";

        System.out.println("Name: " + name);
        System.out.println("Age: " + age);
        System.out.println("Height: " + height);
        System.out.println("Grade: " + grade);
        System.out.println("Is Student: " + isStudent);
    }
}
```

## Key Takeaways

- Every variable in Java has a type, decided at declaration.
- Primitive types store simple values directly; reference types store addresses to objects.
- Use `final` for constants.
- Casting lets you convert between compatible types, either automatically or manually.
