# Input and Output in Java

> Java provides multiple ways to read input from users and write output to the console — from the simple `System.out.println` to the versatile `Scanner` and the efficient `BufferedReader`.

## What You'll Learn

- How `System.out` works — `println`, `print`, and `printf`
- Formatted output with `printf` and format specifiers
- Reading input with `Scanner` — all data types
- The `nextLine()` trap and how to avoid it
- Reading input with `BufferedReader` for better performance
- String formatting with `String.format()`
- Reading and writing files (basic file I/O)
- Standard streams: `System.in`, `System.out`, `System.err`
- When to use `Scanner` vs `BufferedReader`

## Standard Streams in Java

Every Java program has three standard streams available from the moment it starts:

| Stream | Variable | Purpose | Type |
| :--- | :--- | :--- | :--- |
| **Standard Input** | `System.in` | Reads data from the keyboard | `InputStream` |
| **Standard Output** | `System.out` | Prints normal output to the console | `PrintStream` |
| **Standard Error** | `System.err` | Prints error messages to the console | `PrintStream` |

```java
public class StreamDemo {
    public static void main(String[] args) {
        System.out.println("This is normal output");    // goes to stdout
        System.err.println("This is an error message"); // goes to stderr
    }
}
```

Both `System.out` and `System.err` print to the console, but they are separate streams. In production, error output can be redirected to a different file or logging system.

## Output — Printing to the Console

Java provides three main methods for printing output:

### `System.out.println()` — Print with a New Line

Prints the argument and then moves the cursor to the **next line**.

```java
public class PrintlnDemo {
    public static void main(String[] args) {
        System.out.println("Hello");
        System.out.println("World");
    }
}
```

Output:

```text
Hello
World
```

Each `println` call puts its output on a separate line.

### `System.out.print()` — Print without a New Line

Prints the argument but keeps the cursor on the **same line**.

```java
public class PrintDemo {
    public static void main(String[] args) {
        System.out.print("Hello ");
        System.out.print("World");
        System.out.println();  // Just prints a newline
    }
}
```

Output:

```text
Hello World
```

### `System.out.printf()` — Formatted Print

Prints output using **format specifiers**, similar to C's `printf`. The cursor stays on the same line (like `print`).

```java
public class PrintfDemo {
    public static void main(String[] args) {
        String name = "Alice";
        int age = 25;
        double gpa = 3.87;

        System.out.printf("Name: %s%n", name);
        System.out.printf("Age: %d years old%n", age);
        System.out.printf("GPA: %.2f%n", gpa);
    }
}
```

Output:

```text
Name: Alice
Age: 25 years old
GPA: 3.87
```

### Format Specifiers Reference

| Specifier | Data Type | Example | Output |
| :--- | :--- | :--- | :--- |
| `%s` | String | `printf("%s", "Hi")` | `Hi` |
| `%d` | Integer (int, long) | `printf("%d", 42)` | `42` |
| `%f` | Floating-point | `printf("%f", 3.14)` | `3.140000` |
| `%.2f` | Float with 2 decimal places | `printf("%.2f", 3.14159)` | `3.14` |
| `%c` | Character | `printf("%c", 'A')` | `A` |
| `%b` | Boolean | `printf("%b", true)` | `true` |
| `%n` | Newline (platform-independent) | `printf("Hi%n")` | `Hi\n` |
| `%10d` | Right-aligned, width 10 | `printf("%10d", 42)` | `        42` |
| `%-10s` | Left-aligned, width 10 | `printf("%-10s!", "Hi")` | `Hi        !` |

### Practical Formatting Example

```java
public class TableDemo {
    public static void main(String[] args) {
        System.out.printf("%-15s %-5s %-10s%n", "Name", "Age", "City");
        System.out.printf("%-15s %-5d %-10s%n", "Alice", 25, "Mumbai");
        System.out.printf("%-15s %-5d %-10s%n", "Bob", 30, "Delhi");
        System.out.printf("%-15s %-5d %-10s%n", "Charlie", 22, "Bangalore");
    }
}
```

Output:

```text
Name            Age   City      
Alice           25    Mumbai    
Bob             30    Delhi     
Charlie         22    Bangalore 
```

The `-` flag left-aligns the text, and the number sets the minimum column width. This is how you print clean, aligned tables in the console.

## String Formatting with `String.format()`

`String.format()` works exactly like `printf`, but instead of printing directly, it **returns a formatted String** that you can store in a variable:

```java
public class StringFormatDemo {
    public static void main(String[] args) {
        String name = "Ravi";
        int score = 95;

        // Build the string without printing it
        String message = String.format("%s scored %d marks", name, score);

        // Now you can use it wherever you want
        System.out.println(message);          // Print it
        System.out.println(message.length()); // Use it as a normal String
    }
}
```

Output:

```text
Ravi scored 95 marks
21
```

> [!TIP]
> Use `printf` when you want to print immediately. Use `String.format()` when you need the formatted string for later use — such as logging, storing in a variable, or building complex messages.

## Input — Reading from the Keyboard with `Scanner`

The `Scanner` class is the most beginner-friendly way to read user input. It lives in `java.util`, so you must import it.

### Basic Scanner Usage

```java
import java.util.Scanner;

public class ScannerBasic {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Enter your name: ");
        String name = sc.nextLine();

        System.out.print("Enter your age: ");
        int age = sc.nextInt();

        System.out.println("Hello " + name + ", you are " + age + " years old.");
        sc.close();
    }
}
```

### How `Scanner` Works

1. `new Scanner(System.in)` — creates a Scanner that reads from the keyboard (standard input)
2. The Scanner waits for the user to type something and press Enter
3. It then parses the input based on the method you called (`nextInt`, `nextLine`, etc.)
4. `sc.close()` — releases the resource when you are done

### Scanner Methods for Each Data Type

| Method | Reads | Example |
| :--- | :--- | :--- |
| `nextLine()` | Entire line (including spaces) | `"Hello World"` |
| `next()` | Single word (stops at space) | `"Hello"` |
| `nextInt()` | An integer | `42` |
| `nextLong()` | A long integer | `100000L` |
| `nextFloat()` | A float | `3.14f` |
| `nextDouble()` | A double | `3.14159` |
| `nextBoolean()` | A boolean | `true` or `false` |
| `nextByte()` | A byte | `127` |
| `nextShort()` | A short | `32000` |

### Complete Example — Reading All Types

```java
import java.util.Scanner;

public class ScannerAllTypes {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Enter an integer: ");
        int num = sc.nextInt();

        System.out.print("Enter a double: ");
        double decimal = sc.nextDouble();

        System.out.print("Enter a boolean (true/false): ");
        boolean flag = sc.nextBoolean();

        System.out.print("Enter a single word: ");
        String word = sc.next();

        sc.nextLine(); // Consume the leftover newline (explained below)

        System.out.print("Enter a full sentence: ");
        String sentence = sc.nextLine();

        System.out.println("\n--- Your Input ---");
        System.out.println("Integer: " + num);
        System.out.println("Double: " + decimal);
        System.out.println("Boolean: " + flag);
        System.out.println("Word: " + word);
        System.out.println("Sentence: " + sentence);

        sc.close();
    }
}
```

## The `nextLine()` Trap — A Common Beginner Bug

This is the **most common mistake** beginners make with `Scanner`. Understanding it will save you hours of debugging.

### The Problem

```java
import java.util.Scanner;

public class NextLineBug {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Enter your age: ");
        int age = sc.nextInt();

        System.out.print("Enter your name: ");
        String name = sc.nextLine();  // BUG: This gets skipped!

        System.out.println("Age: " + age);
        System.out.println("Name: " + name);  // Prints an empty string

        sc.close();
    }
}
```

When you run this, after typing `25` and pressing Enter, the program **skips** the name input entirely.

### Why This Happens

When you type `25` and press Enter, the input buffer contains: `25\n`

- `nextInt()` reads `25` but **leaves the `\n` (newline character) in the buffer**
- `nextLine()` then reads everything **up to the next newline** — which is the leftover `\n`
- So `nextLine()` immediately returns an **empty string** without waiting for input

### The Fix

Add an extra `sc.nextLine()` call after `nextInt()` (or any `nextXxx()` method) to **consume the leftover newline**:

```java
import java.util.Scanner;

public class NextLineFix {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Enter your age: ");
        int age = sc.nextInt();
        sc.nextLine();  // Consume the leftover newline

        System.out.print("Enter your name: ");
        String name = sc.nextLine();  // Now this works correctly

        System.out.println("Age: " + age);
        System.out.println("Name: " + name);

        sc.close();
    }
}
```

> [!IMPORTANT]
> **Rule of thumb:** Whenever you call `nextInt()`, `nextDouble()`, or any `nextXxx()` method (except `nextLine()`), and the next read is `nextLine()`, always add an extra `sc.nextLine()` in between to clear the buffer.

## Checking if Input is Available — `hasNext` Methods

`Scanner` provides methods to check whether the next token is of a certain type before reading it. This prevents `InputMismatchException`:

```java
import java.util.Scanner;

public class HasNextDemo {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Enter a number: ");

        if (sc.hasNextInt()) {
            int num = sc.nextInt();
            System.out.println("You entered: " + num);
        } else {
            System.out.println("That's not a valid integer!");
        }

        sc.close();
    }
}
```

### Available `hasNext` Methods

| Method | Checks for |
| :--- | :--- |
| `hasNext()` | Any token |
| `hasNextLine()` | A complete line |
| `hasNextInt()` | An integer |
| `hasNextDouble()` | A double |
| `hasNextBoolean()` | A boolean |

## Input — Reading with `BufferedReader`

`BufferedReader` is **faster** than `Scanner` because it reads large chunks of data at once (buffered I/O). However, it only reads **strings**, so you must parse numbers manually.

### Basic BufferedReader Usage

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;

public class BufferedReaderDemo {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        System.out.print("Enter your name: ");
        String name = br.readLine();

        System.out.print("Enter your age: ");
        int age = Integer.parseInt(br.readLine());  // Must parse manually

        System.out.println("Hello " + name + ", age " + age);
        br.close();
    }
}
```

### Breaking Down the Code

```java
BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
```

This looks complex, but it is three layers:

1. **`System.in`** — the raw byte stream from the keyboard
2. **`InputStreamReader(System.in)`** — converts bytes into characters
3. **`BufferedReader(...)`** — adds buffering for efficient reading

### Why `throws IOException`?

`BufferedReader.readLine()` can fail (e.g., if the input stream is closed unexpectedly). Java **forces** you to either handle the exception with `try-catch` or declare it with `throws`:

```java
// Option 1: throws declaration
public static void main(String[] args) throws IOException {
    // ...
}

// Option 2: try-catch
public static void main(String[] args) {
    try {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        String line = br.readLine();
        System.out.println(line);
    } catch (IOException e) {
        System.err.println("Error reading input: " + e.getMessage());
    }
}
```

### Parsing Multiple Values from One Line

When the user enters multiple values separated by spaces on one line:

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;

public class ParseMultipleValues {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        System.out.print("Enter two numbers separated by space: ");
        String line = br.readLine();

        String[] parts = line.split(" ");  // Split by space
        int a = Integer.parseInt(parts[0]);
        int b = Integer.parseInt(parts[1]);

        System.out.println("Sum: " + (a + b));
        br.close();
    }
}
```

If the user types `10 20`, the program outputs `Sum: 30`.

## Scanner vs BufferedReader — When to Use Which

| Feature | `Scanner` | `BufferedReader` |
| :--- | :--- | :--- |
| **Ease of use** | Very easy — built-in type parsing | Harder — must parse manually |
| **Speed** | Slower (parses as it reads) | Faster (buffered reads) |
| **Type parsing** | Built-in (`nextInt`, `nextDouble`) | Manual (`Integer.parseInt`) |
| **Buffer size** | 1 KB | 8 KB (configurable) |
| **Thread safety** | Not thread-safe | Synchronised (thread-safe) |
| **Best for** | Simple programs, quick input, learning | Competitive programming, large input |

> [!TIP]
> **For learning and small programs:** Use `Scanner`. It is simpler and you can focus on logic instead of parsing.
> **For performance-critical code:** Use `BufferedReader`. It handles large volumes of input much faster.

## Reading and Writing Files — Basic File I/O

### Reading a File with `Scanner`

```java
import java.io.File;
import java.io.FileNotFoundException;
import java.util.Scanner;

public class FileReadDemo {
    public static void main(String[] args) {
        try {
            File file = new File("data.txt");
            Scanner sc = new Scanner(file);

            while (sc.hasNextLine()) {
                String line = sc.nextLine();
                System.out.println(line);
            }

            sc.close();
        } catch (FileNotFoundException e) {
            System.err.println("File not found: " + e.getMessage());
        }
    }
}
```

### Reading a File with `BufferedReader`

```java
import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;

public class FileBufferedReadDemo {
    public static void main(String[] args) {
        try (BufferedReader br = new BufferedReader(new FileReader("data.txt"))) {
            String line;
            while ((line = br.readLine()) != null) {
                System.out.println(line);
            }
        } catch (IOException e) {
            System.err.println("Error reading file: " + e.getMessage());
        }
    }
}
```

> [!NOTE]
> The `try (...)` syntax is called **try-with-resources**. It automatically closes the resource (like `BufferedReader`) when the block finishes, even if an exception occurs. This replaces the need for a `finally` block with `br.close()`.

### Writing to a File with `FileWriter`

```java
import java.io.FileWriter;
import java.io.IOException;

public class FileWriteDemo {
    public static void main(String[] args) {
        try (FileWriter writer = new FileWriter("output.txt")) {
            writer.write("Hello, File!\n");
            writer.write("This is line 2.\n");
            writer.write("This is line 3.\n");
            System.out.println("Data written to output.txt");
        } catch (IOException e) {
            System.err.println("Error writing file: " + e.getMessage());
        }
    }
}
```

### Writing to a File with `BufferedWriter`

For better performance (fewer disk writes), wrap `FileWriter` in a `BufferedWriter`:

```java
import java.io.BufferedWriter;
import java.io.FileWriter;
import java.io.IOException;

public class BufferedWriteDemo {
    public static void main(String[] args) {
        try (BufferedWriter bw = new BufferedWriter(new FileWriter("output.txt"))) {
            bw.write("Line 1");
            bw.newLine();  // Platform-independent newline
            bw.write("Line 2");
            bw.newLine();
            bw.write("Line 3");
            System.out.println("Data written with BufferedWriter");
        } catch (IOException e) {
            System.err.println("Error writing file: " + e.getMessage());
        }
    }
}
```

### Appending to a File

By default, `FileWriter` **overwrites** the file. To **append** instead, pass `true` as the second argument:

```java
import java.io.FileWriter;
import java.io.IOException;

public class FileAppendDemo {
    public static void main(String[] args) {
        try (FileWriter writer = new FileWriter("log.txt", true)) {  // true = append
            writer.write("New log entry\n");
            System.out.println("Appended to log.txt");
        } catch (IOException e) {
            System.err.println("Error: " + e.getMessage());
        }
    }
}
```

## Building a Complete Interactive Program

Here is a practical example that combines everything — reading input, processing data, and printing formatted output:

```java
import java.util.Scanner;

public class StudentReport {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        // Read student details
        System.out.print("Enter student name: ");
        String name = sc.nextLine();

        System.out.print("Enter number of subjects: ");
        int numSubjects = sc.nextInt();
        sc.nextLine();  // Consume leftover newline

        String[] subjects = new String[numSubjects];
        int[] marks = new int[numSubjects];
        int total = 0;

        // Read each subject and its marks
        for (int i = 0; i < numSubjects; i++) {
            System.out.print("Enter subject " + (i + 1) + " name: ");
            subjects[i] = sc.nextLine();

            System.out.print("Enter marks for " + subjects[i] + ": ");
            marks[i] = sc.nextInt();
            sc.nextLine();  // Consume leftover newline

            total += marks[i];
        }

        double average = (double) total / numSubjects;

        // Print formatted report
        System.out.println("\n========== STUDENT REPORT ==========");
        System.out.printf("Student Name: %s%n", name);
        System.out.printf("%-20s %s%n", "Subject", "Marks");
        System.out.println("------------------------------------");

        for (int i = 0; i < numSubjects; i++) {
            System.out.printf("%-20s %d%n", subjects[i], marks[i]);
        }

        System.out.println("------------------------------------");
        System.out.printf("Total:               %d%n", total);
        System.out.printf("Average:             %.2f%n", average);
        System.out.printf("Grade:               %s%n", getGrade(average));
        System.out.println("====================================");

        sc.close();
    }

    static String getGrade(double average) {
        if (average >= 90) return "A+";
        if (average >= 80) return "A";
        if (average >= 70) return "B";
        if (average >= 60) return "C";
        if (average >= 50) return "D";
        return "F";
    }
}
```

Sample Run:

```text
Enter student name: Priya
Enter number of subjects: 3
Enter subject 1 name: Mathematics
Enter marks for Mathematics: 92
Enter subject 2 name: Physics
Enter marks for Physics: 85
Enter subject 3 name: Chemistry
Enter marks for Chemistry: 78

========== STUDENT REPORT ==========
Student Name: Priya
Subject              Marks
------------------------------------
Mathematics          92
Physics              85
Chemistry            78
------------------------------------
Total:               255
Average:             85.00
Grade:               A
====================================
```

## Summary

| Concept | Key Points |
| :--- | :--- |
| **`System.out.println`** | Prints output followed by a newline |
| **`System.out.print`** | Prints output without a newline |
| **`System.out.printf`** | Formatted output using specifiers like `%s`, `%d`, `%.2f` |
| **`String.format()`** | Returns a formatted string instead of printing it |
| **`Scanner`** | Beginner-friendly input; built-in type parsing; import from `java.util` |
| **`nextLine()` trap** | After `nextInt()`/`nextDouble()`, call `sc.nextLine()` to consume the leftover newline |
| **`hasNext` methods** | Check input type before reading to prevent `InputMismatchException` |
| **`BufferedReader`** | Faster I/O; reads strings only; must parse numbers with `Integer.parseInt()` |
| **File reading** | Use `Scanner(new File(...))` or `BufferedReader(new FileReader(...))` |
| **File writing** | Use `FileWriter` or `BufferedWriter`; pass `true` to append |
| **Try-with-resources** | `try (Resource r = ...)` auto-closes the resource when done |
| **`System.err`** | Separate stream for error messages; use for error output |
